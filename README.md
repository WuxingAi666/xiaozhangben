# 我的小账本

一款**纯前端、可离线运行**的个人记账 Web 应用，零依赖、单文件即可打开使用。

## ✨ 功能特性

- **日常记账**：收入 / 支出分类记录，随手记账
- **预算管理**：固定支出与日常支出分层统计，清晰掌握可用额度
- **多人日常使用**：已上线并被多人日常使用，数据稳定可靠
- **本地存储**：数据保存在浏览器本地，离线可用，隐私可控

## 🛠 技术栈

- 原生 HTML / CSS / JavaScript（无构建步骤）
- localStorage 本地持久化
- 响应式布局，支持 PC 与移动端

## 🚀 使用方式

直接双击 `index.html` 即可在浏览器中使用，无需安装任何依赖。
